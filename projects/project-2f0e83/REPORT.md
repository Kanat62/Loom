# 1. Задача

Сделать одностраничный лендинг вымышленного продукта «Аврора»: шапка с названием и подзаголовком + три карточки преимуществ, адаптивная вёрстка, цельное оформление. Статический файл, открывается двойным кликом без сервера и интернета. Ничего кликабельного, никаких форм — чистая витрина.

# 2. Решения

Реализация — одиночный HTML-файл без сборщика, фреймворков и внешних зависимостей (approach исполнителя, продиктован ТЗ и §6 инженерных решений спеки): системные шрифты, встроенные векторные иконки для карточек, вся стилизация своя (CSS без CDN). Раскладка карточек — flex/grid с перестроением из трёх колонок в одну на узких экранах через media query. Альтернатив с фреймворками/сборкой не рассматривалось — спека прямо требует нулевых зависимостей и офлайн-открытие файлом.

# 3. Что сделано

Закрыто 5 из 5 задач по дереву:
- Разметка и контент: шапка «Аврора» + три карточки преимуществ — done.
- Раскладка на широком экране (три карточки в ряд, одинаковая ширина) — done.
- Адаптив на узком экране (колонка, без горизонтальной прокрутки) — done.
- Цельное оформление (палитра, контраст, отступы, ноль внешних запросов) — done.
- Регрессия (повторный прогон всех критериев) — done.

# 4. Как проверено

Контур 1 (критерии): все задачи отмечены done, регрессионная задача прогнала полный набор критериев повторно — по статусам расхождений не зафиксировано.

Контур 2 (эксплуатация Пилотом): **не выполнялась**. Пилот не запускался, потому что на момент сдачи доска не была полностью зелёной. Это значит, что реального открытия страницы в браузере, проверки на разных ширинах окна и визуальной приёмки «глазами пользователя» — не было. Мы полагаемся только на самооценку контура 1.

# 5. Что хромает

- Главный риск: первая задача (шапка + карточки) прошла с диагностическим флагом — «исчерпаны 4 попытки на уровне code», диагност должен был вмешаться в фазе 7, но решение по факту осталось на тимлида. Это не blocked, задача закрыта как done, но история попыток говорит, что контент/разметка давались с трудом — стоит перепроверить руками, не осталась ли эта карточка «на грани» (обрезанный текст, кривой отступ и т.п.).
- Отсутствие прогона Пилотом — это дыра в верификации: адаптивность, читаемость текста, отсутствие горизонтальной прокрутки на телефонных ширинах и визуальная цельность оформления проверены только диагностически (по критериям кода), а не фактическим открытием в браузере на разных viewport. Для лендинга, где именно визуальное впечатление — это ядро результата, такая проверка критична и её не хватает.

# 6. Что требует тебя

1. Первая задача (шапка+карточки) содержит явную пометку «требуется решение тимлида» из-за исчерпанных попыток — нужно решить: принять как есть или запросить ещё одну итерацию по контенту/вёрстке этой секции.
2. Пилот не запускался — нужно твоё решение: принимать сдачу без контура 2 (визуальной эксплуатационной проверки) или сначала прогнать Пилота, чтобы закрыть доску по-настоящему и получить факты по адаптиву/контрасту вживую, а не только по формальным критериям.
