# Дизайн-система

## Направление
Кинематографичное тёмное — интерфейс монтажной комнаты: почти чёрный нейтрально-холодный фон, свет только там, где картинка, единственный тёплый янтарный акцент как свет проектора, никакого декора и цветных плашек.

## Обоснование (референс)
Направление выбрано человеком из предложенных — «Кинематографичное тёмное». Опора: интерфейсы профессиональных монтажных инструментов (DaVinci Resolve, Premiere) — тёмная нейтральная среда, чтобы глаз судил о картинке, а не о UI; единственный тёплый янтарный акцент как свет проектора; моноширинные таймкоды как отраслевая норма. Никаких элементов других стилевых направлений в продукт не добавляется.

## Правила для Исполнителя
- Все цвета, размеры, отступы, радиусы, тени и длительности берутся ТОЛЬКО из переменных этого файла. Ни одногоハ hex-литерала, ни одного произвольного px в компонентах — иначе правка отклоняется.
- Фон приложения — var(--surface); панели и карточки — var(--surface-variant); поповеры/модалки — var(--surface-raised). Область под видео и внутри превью-телефона — var(--canvas), она темнее всего интерфейса: свет только там, где картинка.
- Акцент один — var(--accent). Им окрашены ровно две вещи на экране: главное действие текущего состояния (Загрузить → Скачать) и контур активной вертикальной рамки. Ни один второй элемент акцентом не красится.
- На экране одно доминирующее действие. До загрузки файла это кнопка загрузки (solid accent, крупная); после загрузки — «Скачать». «Автоматически» — переключатель (ToggleButton), не solid-accent-кнопка; управление плеером — иконочные кнопки без заливки.
- Текст: основной — var(--text-base) цветом var(--content); вторичный — var(--text-sm) цветом var(--content-secondary). var(--content-muted) запрещён для читаемого текста (только декоративные метки шкалы). Размеры мельче var(--text-sm) допустимы лишь для таймкодов моношрифтом.
- Семейств шрифтов ровно два: var(--font-sans) для всего интерфейса и var(--font-mono) исключительно для цифр времени, длительности и размера файла с font-variant-numeric: tabular-nums (чтобы цифры не дёргались при воспроизведении).
- Все отступы, размеры и зазоры — кратны 4px и берутся из шкалы --space-1…--space-8. Внутренний padding панелей — var(--space-5), зазор между колонками рабочей области — var(--space-5), между связанными контролами — var(--space-2).
- Радиусы: контролы и кнопки — var(--radius-md), панели и карточки — var(--radius-lg), превью-телефон — var(--radius-xl), чипы/индикаторы — var(--radius-full). Само видео-полотно — var(--radius-none): кадр не скругляется.
- Тень означает уровень над поверхностью: панели в потоке — без тени, только 1px var(--border); поповеры и тултипы — var(--shadow-2); модалки и оверлей прогресса — var(--shadow-3). Тень «для красоты» запрещена.
- Рамка поверх кадра рисуется как контур var(--frame-guide) толщиной 2px плюс затемнение var(--frame-shade) на области ВНЕ рамки — так глаз читает кадрирование мгновенно. При включённой автоматике контур окрашивается в var(--track-auto), при ручном ведении — в var(--accent).
- Позиция рамки и превью НЕ анимируются средствами CSS: никаких transition/animation на transform или left рамки и содержимого превью — движение задаётся только логикой сглаживания в коде, иначе появится видимая задержка за курсором.
- Функциональные анимации только для смены состояний UI: длительность var(--duration-fast)/--duration-base/--duration-slow с var(--ease-standard). Ничего дольше 250 мс, никаких пульсаций, свечений и параллакса.
- Дорожка положений рамки под плеером: высота 8px (var(--space-2)), фон var(--track-empty), автоматические участки — var(--track-auto), участки, записанные мышью, — var(--track-manual). Легенда из двух подписей обязательна: одного цвета недостаточно для понимания.
- Фокус виден всегда: 2px outline var(--accent-ring) с offset 2px. Удаление outline без замены запрещено. Контраст границ интерактивных элементов — не ниже var(--border-strong).
- Ширина текстовых блоков (сообщения об ошибке, подсказки, описание) ограничена var(--measure-text); рабочая область ограничена var(--app-max) и центрируется; колонка превью — фиксированные var(--panel-preview), остаток отдан видео.
- Продукт десктопный: при ширине окна < 1024px вместо ломаной раскладки показывается один центрированный блок-сообщение «Нужен компьютер с мышью» на var(--surface). Проверка обязательна: при 375px нет горизонтальной прокрутки и ни один элемент не выходит за вьюпорт.
- Прогресс сборки файла — ProgressBar с заливкой var(--accent) и подписью процента моношрифтом; во время сборки главное действие переходит в disabled, а не исчезает (макет не должен прыгать).
- Ошибки (формат, размер, длительность) — Alert со статусом danger: цвет var(--danger), текст var(--content), одна строка причины плюс одна строка, что сделать. Красным ничего кроме ошибок не красится.
- Компоненты — только те, что есть в индексе HeroUI v3 (Button, ToggleButton, Slider, Card, Surface, Toolbar, ProgressBar, Alert, Tooltip, Modal, Separator, Typography, Spinner). Чего нет в индексе — собирается из div/button с классами Tailwind и переменными этой системы; выдумывать API HeroUI запрещено.
