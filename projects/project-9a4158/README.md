# Vertical Reframe

Веб-сервис превращает горизонтальный ролик в вертикальное видео 9:16 под экран телефона. Рамка ведётся мышью прямо во время просмотра либо автоматически — по говорящему в кадре.

## Установка и запуск

Установка: npm install

Сборка: npm run build

Запуск: npm start

После запуска сервис доступен по адресу http://localhost:3000

Порт задаётся переменной окружения PORT (по умолчанию 3000).

Браузер для автоматических проверок: npm run setup:browsers

Тестовые фикстуры: node scripts/make-fixtures.mjs

## Сценарий использования

1. Загрузка файла — открывается плеер с широким кадром, вертикальной рамкой и превью справа.
2. Ведение мышью — во время воспроизведения рамка следует за курсором, положение запоминается.
3. Кнопка «Автоматически» — рамка сама едет к говорящему; ручной проезд перезаписывает только свой отрезок.
4. Кнопка «Скачать» — сервис собирает итоговый файл и отдаёт ссылку на скачивание.

Загрузка нового файла сбрасывает предыдущую работу.

## Ограничения входа

- Формат: mp4 или mov
- Длительность: до 5 минут
- Размер: до 500 МБ
- Один файл за раз; при превышении лимитов показывается понятное сообщение.

## Параметры выхода

- Контейнер mp4, пропорции 9:16
- Высота кадра как у исходника, ширина по пропорции
- Длительность и звук исходника сохраняются

## Границы применимости

Нет монтажа, обрезки, титров, эффектов, работы со звуком, разделения экрана, учётных записей и пакетной обработки. Интерфейс рассчитан на десктопный браузер с мышью.
